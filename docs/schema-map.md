## Merchant workflows

1. **Ring a sale.** Clock in (`Shift`) → open a till (`RegisterSession`, `CashMovement` opening float) → basket (`Cart`, `CartLine`; barcode → `ProductBarcode` → `ProductVariant`, price from `PriceBookEntry`, tax from `TaxRate`, promotion `Promotion`/`PromotionRule`, ID check `AgeVerification` against `CompliancePolicy`) → tender (`Tender`, cash `CashMovement`) → `Sale` + `SaleLine` (stock drawn from `StockLevel`/`InventoryLot` with `InventoryLedgerEntry`; points to `LoyaltyAccount` with `LoyaltyLedgerEntry`; `PromotionRedemption`) → receipt.
2. **Refund, return or void.** Find the sale → `Refund` + `RefundLine` + `RefundTenderAllocation`, `Return` + `ReturnLine` (restock ledger entry), loyalty reversal; or void a cash sale on its own open till.
3. **Close the till and the day.** Paid in/out and safe drops (`CashMovement`) → count and close (`RegisterSession` counted cash, over/short) → close shift → generate and approve the store day (`StoreDay`, `StoreDayLine`) → bank deposit (`BankDeposit`) → accounting export (`ExportBatch`, `ExportLine`).
4. **Keep the catalog.** Create or edit an item (`Product`, `ProductVariant`, `ProductBarcode`, `ProductCategory`, `TaxCategory`) → publish prices (`PriceBookEntry`) → promotions → restricted-sale policy (`CompliancePolicy`) → retire (status discontinued).
5. **Keep stock right.** Stock by location (`StockLevel`) → lots and expiry (`InventoryLot`) → counts (`InventoryCount`, `InventoryCountLine`) → adjustments and waste (`InventoryLedgerEntry`, `WasteEvent`) → transfers between stores (`InventoryTransfer` and lines).
6. **Buy from vendors.** Vendors and their items (`Vendor`, `VendorItem`) → draft, submit and approve a PO (`PurchaseOrder`, `PurchaseOrderLine`) → receive a delivery (`Receiving`, `ReceivingLine`, lots and ledger).
7. **Run the forecourt.** Topology (`FuelSite`, `FuelGrade`, `FuelTank`, `FuelPump`, `FuelNozzle`) → prices (`FuelPrice`) → pump sale (`FuelTransaction`) → readings and deliveries (`FuelTankReading`, `FuelDelivery`) → wet-stock reconciliation (`FuelReconciliation`).
8. **Lottery and money services.** Game → pack custody → sold ranges → daily settlement (`LotteryGame`, `LotteryPack`, `LotteryPackEvent`, `LotterySettlement`). Provider → confirmed transaction → settlement (`MoneyServiceProvider`, `MoneyServiceTransaction`, `MoneyServiceSettlement`).
9. **Prepared food.** Recipe → prep batch → output lot → waste (`Recipe`, `RecipeIngredient`, `PrepBatch`, `WasteEvent`).
10. **Customers and loyalty.** Program → enrol members → earn and redeem at the register → adjust or expire (`LoyaltyProgram`, `LoyaltyAccount`, `LoyaltyLedgerEntry`).
11. **Staff.** Add a person (`User` + `Employee` with `Role` and stores) → set their POS PIN → shifts and tills → leave, suspend or terminate.
12. **Payments and integrity.** Providers → settlement reconciliation (`PaymentProvider`, `PaymentReconciliation`); alerts (`OperationalAlert`); offline devices and replay; dead-letter replay (`OfflineDevice`, `OfflineOperationBatch`, `OutboxEvent`).
13. **Storefront (customer).** Browse aisles and products → product detail (price, options, "In store") → account → points balance and receipts.
